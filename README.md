# AI 复习问答系统（基于通义千问 / DashScope）

上传学习笔记，由通义千问自动生成多题型题目，通过对话刷题、考试模式、AI 追问、错题本、数据分析等全方位方式高效复习。

> 仅依赖 Flask + SQLite + DashScope API

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 📝 **上传笔记出题** | 支持 Markdown/TXT/代码等文件，AI 自动抽题 |
| 💬 **对话式刷题** | 一问一答，立刻给出评分+解析+点评 |
| 🔍 **AI 追问** | 对任意题目深度追问，AI 展开讲解/举例/对比 |
| 📋 **全文搜索+筛选** | 搜题干/答案/解析 + 题型/难度/知识点/模块过滤 |
| 🧪 **考试模式** | 限时组卷 → 倒计时答题 → 自动评分 → 成绩报告 |
| 📖 **案例分析题** | 案例材料 + AI 三维评分（覆盖度/深度/逻辑） |
| 📈 **数据仪表盘** | 总体正确率 + 每周趋势 + 知识点雷达图 + 薄弱点预警 |
| 🔄 **重新生成题目** | 已有笔记一键重新出题，支持更换题型和数量 |
| ❌ **错题本** | 自动收集错题，支持集中重练 |
| 📤 **导出** | 导出 TXT / Markdown，方便离线复习 |
| 💾 **断点续练** | 退出后自动保存进度，下次继续 |

## 3. 功能详解

### 3.1 上传笔记并生成题目

首页支持上传 Markdown / TXT / 代码等文本文件。上传时可配置：

- **题型**：单选题、判断题、简答题、案例分析题（可多选）
- **目标题量**：AI 尽量生成接近指定数量的题目

AI 会自动从笔记中提炼知识点标签，生成题目（题干、选项、标准答案、解析），并按题干去重。

每次上传在数据库中记录为一个「模块」，后续可按模块选择题目来源。

右侧面板支持 **模块管理**（查看笔记内容、管理题目、**一键重新生成题目**）和 **导出**（TXT / Markdown）。

### 3.2 对话式刷题（练习）

配置题源模块、题型、知识点、题量后，进入一问一答的对话式刷题：

- **单选题/判断题**：选择选项后提交，立即显示正误
- **简答题**：提交后由 AI 评分（0~100 分），附带中文点评
- **案例分析题**：先看案例材料再作答，AI 从要点覆盖、分析深度、逻辑清晰三个维度评分
- **AI 追问**：答完每道题后，可在追问框输入问题（如"展开讲讲"、"举个例子"），AI 结合题目上下文深度讲解
- **断点续练**：进度自动保存到浏览器，关闭后回来可继续

### 3.3 全文搜索 + 高级筛选

支持关键词搜索题干、答案、解析、案例材料、知识点标签，配合题型、难度、知识点、模块组合筛选，快速定位目标题目。

### 3.4 考试模式

- 配置题量、时限、题型、难度、题源模块
- 全屏答题界面，左侧题号导航（已答/未答高亮）
- 右上角倒计时，超时自动交卷
- 提交后生成完整的成绩报告：
  - 总分、正确率
  - 各知识点掌握度分析（占比条）
  - 每题详情（你的答案 vs 标准答案）

### 3.5 错题本

自动收集所有历史错题，支持集中重练，方便查漏补缺。

### 3.6 数据仪表盘

- 总体数据：总答题数、正确数、正确率
- **知识点掌握度雷达图**：各知识点正确率可视化，低于 40% 的薄弱点自动标红预警
- **每周正确率趋势**：折线图展示每周正确率变化

### 3.7 导出

支持导出 TXT 或 Markdown 格式，可选指定模块或全部题目，方便离线打印或导入其它工具。

## 4. 与 DashScope 的集成说明

所有 AI 调用封装在 `dashscope_client.py`：

| 方法 | 用途 |
|------|------|
| `generate_questions_from_note()` | 从笔记生成题目（多题型） |
| `score_answer()` | 简答题评分 |
| `score_case_answer()` | 案例分析题三维评分 |
| `follow_up_chat()` | AI 追问深度讲解 |

迁移到其他模型供应商只需改写该文件，Flask 其余部分无需改动。

---

## 5. 数据存储

使用 SQLite，默认文件 `data.db`：

- **notes**：笔记模块
- **questions**：题目（含案例材料、题型、选项、答案、解析、难度）
- **user_answers**：作答记录

> 数据库和上传的笔记文件默认被 `.gitignore` 忽略。
